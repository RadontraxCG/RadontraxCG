## What I do

- **Hosting** - [Wattle Cloud](https://wattlecloud.com), my own hosting platform for websites, apps, Discord bots, databases and game servers, in Brisbane and the UK. Built from the ground up: builds, edge, sandboxing, backups and billing.
- **Web apps** - Next.js, React and Tailwind on top of Node.js APIs. Dark, clean and fast, built from scratch.
- **Discord bots** - trading economies, music and voice, VM control panels, status monitors. All database-backed, all running 24/7.
- **Infrastructure** - dedicated servers with OVH and BinaryLane, Proxmox virtualisation, Docker, gVisor and Cloudflare. I run the metal my code lives on.
- **Automation** - scrapers, monitors, OCR pipelines and desktop automation. If I have to do it twice, it gets scripted.
